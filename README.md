## Features

* **Responsive Navigation:** Fully functional mobile hamburger menu and smooth scroll-to-section transitions.
* **Dynamic Skill Slider:** A custom-built vertical slider integrated with **Lottie animations** to visually represent technical proficiencies.
* **Interactive Project Gallery:** A horizontal scroll-wrapper featuring hover-reveal layers for project details and external links.
* **Intersection Observer API:** Implemented for scroll-triggered "fade-up" and "fade-down" animations to improve UI/UX flow.
* **Integrated Contact Form:** A functional contact section using the **Fetch API** to send form data directly to a Google Sheets backend via Google Apps Script.

## Tech Stack

* **Frontend:** HTML5, CSS3 (Custom animations/Flexbox/Grid), Vanilla JavaScript.
* **Animations:** LottieFiles (JSON-based animations).
* **Typography & Icons:** Google Fonts (Inter), FontAwesome.
* **Tools:** Blender (3D Modeling), Figma (UI Design), Adobe Creative Cloud.

## Highlighted Project: "Magic Mushroom"
A key feature of this portfolio is the **Magic Mushroom** 3D animation project. 
* **The Project:** An opening cinematic for a short film exploring surreal time dimensions.
* **The Tech:** Created entirely in **Blender**, focusing on atmospheric lighting, procedural texturing, and stylized animation.
* **The Result:** A high-fidelity sequence that establishes the visual tone for a narrative project.
